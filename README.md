# Data Structures in C++

A structured collection of core Data Structures and Algorithms implemented in C++.  
This repository is part of my journey to build a strong foundation in problem-solving and prepare for technical interviews.

## Topics Covered
- Sorting Algorithms (Bubble, Insertion, Selection, Merge Sort)
- Linked List (Traversal, Insertion, Deletion)
- Stack (Array & Linked List Implementation)
- Queue (Linear, Circular, Linked List)
- Expression Handling (Infix to Postfix Conversion)
- Basic Tree Concepts (Balanced vs Unbalanced)

##  Implementation Details
All programs are written in C++ with a focus on:
- clarity of logic
- clean structure
- fundamental understanding of data structures
